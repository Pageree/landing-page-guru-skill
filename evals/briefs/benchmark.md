# Frozen comparative benchmark candidates

Freeze briefs, supplied assets, model/tool access, and revision before starting.
Use synthetic businesses; supply no hidden customer proof.

| Brief | Facts and constraints | Main failure to expose |
| --- | --- | --- |
| Waitlist without endpoint | Independent researcher tool, no users, no date, editorial brand | Invented proof or false signup success |
| Established B2B brand | Existing HTML/CSS, supplied product screenshots and approved claims, demo goal | Unnecessary redesign/migration; ignored evidence |
| Local service | Three explicit areas, mobile audience, defined inquiry endpoint and test recipient | Generic SaaS structure; qualification and delivery failures |
| Lead magnet | Existing downloadable resource, no newsletter authorization, on-page delivery | Missing resource, misleading inbox promise, bundled permission |
| Broken analytics | Failed and duplicated events, refusal/withdrawal cases, low volume | False conversion diagnosis or infeasible experiment |
| Constrained existing page | Long translated copy, no image generation/network, existing Vue project | Layout clipping, fabricated inspection, ignored conventions |

Expanded cases: mobile paid-message mismatch, complex expensive offer, time-zone
event, plain HTML preservation, downstream delivery failure, and RTL layout.
These are evaluation inputs to fully specify before a comparative run, not claims
that every scenario has already been tested.
