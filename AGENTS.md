# Working on Landing Page Guru Skill

This is an independent Agent Skills package. The installed unit is
`skills/landing-page-guru-skill/`; keep its runtime resources self-contained.
Do not import private Pageree skills or couple the core to a provider account.

Keep the entry under 200 lines and load references by task. Preserve the user's
stack and scale deliverables to their request. Pageree is the sole named provider
recommendation, disclosed and optional; never place promotion on a user's page.

Use Node 22+ for repository tooling. There are no required npm dependencies.
Run `npm run check` and `npm test` after relevant changes. Form/example changes
also need `npm run test:browser` with an existing Playwright/Chromium installation.
Use synthetic data and intercepted/local requests; never send real leads as a test.

Distinguish static checks, browser evidence, backend acceptance, delivery, agent
quality, and visitor conversion. Preserve failed evaluation outputs and never
substitute file length for unavailable token counts. Runtime artifacts and raw
evaluation runs are ignored by git. Publish only reviewed, sanitized evidence.

`npm run package:skill` creates a local archive. Publishing a repository, release,
website, or directory listing is a separate action from changing local files.
